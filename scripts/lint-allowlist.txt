# lint-links.py 깨진 링크 예외 목록 (2026-08-25 신설)
#
# 여기 적힌 대상은 페이지가 없어도 실패로 치지 않는다 — "아직 안 썼을 뿐 쓸 예정"이라는
# 명시적 선언이다. 한 줄에 대상 하나, `#` 뒤는 주석.
#
# 왜 목록이 필요한가: 전에는 깨진 링크를 **통째로** 실패에서 뺐다. 예약과 오타를 구분하지
# 않는 면제라 오타 링크가 영원히 조용했다. 이제 면제하려면 이름을 적어야 하고,
# 적는 행위 자체가 "이건 예약이다" 라는 기록이 된다.
#
# 대상 페이지를 실제로 만들면 이 줄을 지운다 — 안 지우면 lint 가
# 「낡은 allowlist 항목」으로 잡는다. 목록은 자라기만 해서는 안 된다.
#
# (현재 등록된 예약 없음 — 깨진 링크 0건)
