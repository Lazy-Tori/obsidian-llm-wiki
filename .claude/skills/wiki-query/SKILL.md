# wiki-query — 위키에 쌓인 것으로 답한다

```bash
VAULT="${VAULT_PATH:-$HOME/second-brain}"   # 어느 디렉토리에서 부르든 이 볼트가 대상
```

## 순서

**`index.md` → 후보 페이지 → 필요하면 `raw/` 원본.**
index 를 건너뛰고 grep 부터 하지 않는다 — index 가 이 볼트의 검색 진입점이다.

상세는 `$VAULT/CLAUDE.md` 「오퍼레이션 > Query」 와 규약 §7.

## 규칙 넷

1. **근거를 `[[링크]]` 로 단다.** 위키에 없는 일반론을 섞을 거면
   「위키 밖 내 의견」으로 분리한다 — 내 기록에 근거한 답이라는 게 이 스킬의 전부다
2. ⚠️ **`wiki/` 0건은 침묵이 아니라 탐색 미완이다.** "기록 없음"을 선언하기 전에
   `raw/` 를 본다. (2026-08-25 실패: wiki 0건을 곧바로 "없음"으로 답했으나
   `raw/docs` 에 직접 관련 자료 3건이 있었다)
3. **진짜 침묵이면 침묵을 보고한다.** 그 주제가 볼트의 빈 영역이라는 유의미한 답이다
4. **재사용할 답은 `wiki-ingest` 로 넘긴다** (규약 §6.1). 대화에만 둔 답은 사라진다

다른 폴더에서 호출됐으면 답을 마친 뒤 원래 작업으로 복귀한다.
