# wiki-lint — 위키 건강 점검

```bash
# 어느 디렉토리에서 부르든 이 볼트가 대상.
# 설치할 때 자기 볼트 경로로 고치거나 VAULT_PATH 를 내보낸다
VAULT="${VAULT_PATH:-$HOME/second-brain}"
```

절차 원문: `$VAULT/CLAUDE.md` 「오퍼레이션 > Lint」 · 규약 §8(체크리스트·보고 형식)·§8.1(무인).

## 1단계 — 기계 검사

```bash
cd "$VAULT" && python3 scripts/lint_all.py     # --verbose 로 전문
```

| 검사 | 잡는 것 |
|---|---|
| `links` | 깨진 링크(allowlist 미등록분) · 이름 충돌 · 고아 · 안 걸린 일지 |
| `backlinks` | 소스가 선언한 갱신이 실제로 반영됐나 |
| `frontmatter` | 필수 필드 · 날짜 형식 · 허용값 |
| `index-stats` | 「현황」 숫자 · inbox 잔량 |
| `freshness` | 스탬프 없는 휘발성 사실 · 낡은 스탬프 |
| `lessons` | 방치 · `superseded_by` · `confidence` 계약 |
| `raw-coverage` | wiki 가 안 가리키는 raw 원본 |

⚠️ **exit 0 ≠ 깨끗함** — 이 둘은 요약이 아니라 출력을 읽는다:

- **allowlist 예약분**(`scripts/lint-allowlist.txt`)은 통과로 뜬다
- `index-stats` 는 「현황」에 없는 항목을 못 본다 → `부분 대조 (n/m)`.
  미대조 목록이 뜨면 그 줄을 현황에 추가하자고 제안한다

## 2단계 — 의미 검사 (이게 본체)

기계가 못 잡는 몫. 항목별 시작점:

- **모순** — `2-lessons/` 전수 + 최근 30일 `1-experiments/`. 고치기 전에
  **모순인가 진화인가** 구분 (진화면 `superseded_by`, 모순이면 confidence 하향 + 반례)
- **노후 lesson** — 180일 방치는 기계가 잡는다. 사람 몫은 **최근 경험이 뒤집었는데
  그대로인 것** (날짜가 아니라 내용이 근거)
- **선언·실제 불일치** — 링크 존재는 `backlinks` 가 본다. 사람 몫은 **역링크는 걸렸는데
  내용이 안 바뀐 경우**
- **stub 방치** — `concepts/` 에서 `stub` 인 채 30일 넘은 것
- **근거 부족** — `solid` 인데 근거 2개 미만. 개수 전에 **주장의 형태**를 본다 (규약 §5)
- **승격 후보** — 눈에 띄는 것만. 깊게 파려면 `wiki-emerge` 로 넘긴다

## 3단계 — 보고

**깨짐 → 낡음 → 후보** 순으로 묶고, 항목마다
`파일 — 무엇이 틀렸나 — 고치면 어떻게 되나`. 기계 발견은 스크립트 이름을 같이 적는다.

## 원칙

- **보고하되 자동으로 고치지 않는다.** 고칠지 묻고, 여럿이면 하나씩 고르게 한다
- 깨끗하면 **짧게** 깨끗하다고 한다 — 억지 발견을 만들지 않는다
- 고친 뒤 `lint_all.py` 를 통째로 다시 돌린다 (페이지를 고치면 링크·숫자·역링크가 같이
  움직인다). 통과 확인 후 `log.md` 에 `## [YYYY-MM-DD] lint | 제목`
- **개수를 외워 쓰지 않는다** — 러너가 `lint-*.py` 를 글롭한다
  (`lintlib.py`·`lint_all.py`·`lint_autofix.py`·`lint_morning.py` 는 하이픈이 없어 안 걸린다)

## 무인 실행과의 관계

매일 08:30 launchd 가 `lint_morning.py` 를 돌려 **정답이 하나뿐인 셋**만 고치고
(낡은 allowlist·현황 숫자·`updated` 보정) 나머지는 볼트 루트 **`볼트-백로그.md`** 에
남긴다 (일지에는 쓰지 않는다 — 규약 §11). 사람이 그 줄을 처리해 달라고 하면
이 스킬로 처리하고, 고친 뒤 **그 줄을 백로그에서 지운다**(`[x]` 가 아니라 삭제 —
이력은 `log.md`). 범위는 규약 §8.1.
